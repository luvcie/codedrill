# Rank thresholds

All 20 built-in exercises use individually chosen cutoffs. D rewards any successful completion. Every timed cutoff is strict: exactly 2:30 does not earn a rank requiring under 2:30. Times below use `minutes:seconds`.

These targets estimate writing a complete, working solution from memory in an empty student file. They allow for declarations, headers, edge cases, and cleanup. Supplied test programs and base implementations are already present in the workspace. They are design estimates, not percentiles measured from player runs.

D+ through C+ leave room for recall and correction. The B and A ranks reward increasing fluency. S through SS require a well-practiced solution; U and X require exceptional recall and execution. The vect2 schedule is unchanged. Custom drills retain their existing difficulty-based cutoffs until their requirements can be reviewed.

| Exercise | Basis for the targets |
|---|---|
| `ft_strlen` | A counter and a null-terminator loop; no allocation or helper files. |
| `ft_swap` | Three assignments through pointers; recall is shorter than a scan, but the function still has to be typed. |
| `ft_split` | Count and extract words across three delimiters, allocate each word, terminate the array, and clean up partial allocation failures. |
| `reverse_bits` | A fixed eight-step loop, with masks, shifts, and unsigned-byte handling to recall correctly. |
| `two_sum` | Write the Go package and function, track prior indices, and check the complement before insertion so duplicates work. A quadratic search is also allowed by the statement. |
| `palindrome` | Python character filtering, case normalization, and comparison with the reverse; empty normalized input must pass. |
| `ft_atoi` | Recall all six whitespace characters, one optional sign, and digit accumulation that stops at the first non-digit. |
| `binary_search` | Maintain the search interval and midpoint updates, including empty input and unsuccessful searches, while preserving logarithmic complexity. |
| `ft_itoa` | Count digits, allocate and fill backwards, handle zero and the sign, and avoid overflow when converting INT_MIN. |
| `valid_parentheses` | A stack and delimiter mapping, with guards for unmatched closing delimiters and a final empty-stack check. |
| `ft_strrev` | Find the end, swap inward, return the original pointer, and handle an empty string without indexing before its start. |
| `ft_list_size` | Include the supplied header and count nodes until NULL. No list structure or allocation needs to be written. |
| `max_subarray` | Initialize Kadane's recurrence from the input so all-negative arrays return a negative maximum. |
| `ft_strdup` | Measure the string, allocate including the terminator, check allocation, and copy into independent storage. |
| `climb_stairs` | A compact Fibonacci recurrence with the correct starting values for one and two stairs. |
| `vect2` | Unchanged reference scale: two files, const and mutable indexing, scalar arithmetic, reference-returning compound operators, increments, comparisons, and stream output. |
| `bigint` | Two files with arbitrary-precision carry arithmetic, decimal shifts, large shift counts, normalized zero, increment semantics, and six comparisons. Multiplication and division are not required. |
| `polyset` | Six student files with multiple inheritance, canonical-form forwarding, two membership searches, and a non-owning deduplicating wrapper. Base containers and their storage are supplied. |
| `life` | Read drawing commands, clamp the pen, allocate two boards, count eight neighbors without wrapping, update simultaneously, print exact output, and release memory. |
| `bsq` | Parse two header formats, validate map shape and markers, solve the largest square with deterministic ties, and handle stdin, multiple files, errors, separators, and cleanup. |

The schedules are stored in `internal/drill/rank_times.go`. Personal bests retain their saved durations and receive the current rank when displayed.
